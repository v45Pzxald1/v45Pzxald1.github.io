一、进展总结

不使用计算机的计算机科学教育活动就是不插电（unplugged）编程。

九年一贯制编程课程体系

低年级以具象思维为主，适合“不插电”的动手操作；中年级形象思维成熟，可过渡到 “图形化编程” 的可视化操作；高年级抽象思维萌芽，能理解 “C++”的代码逻辑和语法规则。

项目背景

  1. 课程体系需求：构建北校区九年一贯制编程课程体系，填补低段启蒙空白。

  2. 素养落地需求：精准对接小学信息科技与小学数学核心素养，实现跨学科育人。

  3. 低段教学适配：根据一、二年级学生认知特点，避免过早依赖电子设备。

  4. 现有课程契合：当前小学信息科技课已普遍融入不插电学习形式。

素养落地

核心素养对应表
学科 核心素养 不插电编程中的落地载体
小学数学 数感、运算能力、推理意识、模型意识、几何直观、空间观念 排序游戏（数感）、条件分类（推理意识）、规律递推（模型意识）、迷宫行走（空间观念）
小学信息科技 信息意识、计算思维、数字化创新与发展、信息社会责任 指令执行（计算思维）、活动设计（数字化创新）、规则遵守（信息社会责任）、问题调试（信息意识）

不插电编程课程内容以游戏、卡片、手工互动等实物形式，聚焦计算思维，实现信息科技与多学科素养的跨学科落地。

不插电编程本学期总结

  1. 试点任务核心达成：刘淑梅、赖秋艳、唐繁茂三位老师牵头，在二年级数学思维 A、B 班顺利落地教学，完成顺序、循环、分支 3 个核心主题的课程教学，学生任务完成度优异。

  2. 跨学科协作深化：建立了数学与信息教师协同备课机制。

  3. 教学模式创新试点：“不插电编程 + 小程序” 效果不错。

  4. 体系化建设铺垫：梳理形成 3 节可直接复用的课程，为后续教学全面铺开打好基础。

二、优点分析

优点分析

  1. 课程落地见效，学生收获显著。数学教师学情分析精准，不插电编程的游戏化动手操作，降低了编程抽象概念的理解门槛，教学效果突出。

  2. 生自主打印不插电教具材料，参与兴致浓厚，课堂体验良好。

  3. “不插电 + 小程序” 创新模式成效显著，兼顾具象体验与趣味复习，提升知识留存率。

  4. 跨学科协作模式成熟，具备可复制性。

三、问题梳理

问题梳理

  1. 教学内容适配不足：核心知识点（如分支结构）预判不足，学生理解难度超预期。

  2. 教学资源不足：小程序配套滞后，书籍、不插电器材有缺口。

  3. 教师资源未充分利用：仅二年级试点，其他教师参与不进来。

  4. 缺固定备课机制。

  5. 课程评价不完善：缺失过程性评价。

  6. 课程衔接有效性未验证（个人预判良好）。

  7. 保障缺口：需专项经费（书籍、器材、小程序）。

四、改进措施

改进措施

  1. 构建教师梯队：明确分工，跨年级组建备课组，。

  2. 验证课程衔接：跨学期跟踪学生，开展跨年级试点，形成衔接方案。

  3. 前置资源建设：制定同步配套计划，补齐书籍、教具、小程序等缺口。

  4. 申报各级课题，探索引入资源。

五、下一步工作计划

下一步工作计划

  1. 试点教师完成总结与教案优化归档。

  2. 师资补充：申请新老师加入。

  3. 新学期筹备：开学前明确授课内容、人员、对象；建立备课制度与共享平台，激励机制。

  4. 小程序对接：提前备课，明确需求后开发程序（信息老师主导）。

  5. 特色活动：结合科技节策划编程成果展或赛项。

  6. 评价体系：研讨制定过程性评价实施方案。
