一、项目背景

不使用计算机的计算机科学教育活动就是不插电（unplugged）编程。

项目背景

  1. 课程体系需求：构建北校区九年一贯制编程课程体系，填补低段启蒙空白。

  2. 素养落地需求：精准对接小学信息科技与小学数学核心素养，实现跨学科育人。

  3. 低段教学适配：根据一、二年级学生认知特点，避免过早依赖电子设备。

  4. 现有课程契合：当前小学信息科技课已普遍融入不插电学习形式。

北校区九年一贯制编程课程体系

我校北校区构建 “一二年不插电编程→三四年图形化编程→五六年C++编程→七八年级信息学竞赛”的九年一贯制编程课程体系，实现从计算思维启蒙到算法竞赛储备的渐进式培养。

二、课程内容

课程内容以游戏、卡片、手工互动等实物形式，聚焦计算思维，实现数学与信息科技素养的跨学科落地。

素养落地

核心素养对应表
学科 核心素养 不插电编程中的落地载体
小学数学 数感、运算能力、推理意识、模型意识、几何直观、空间观念 排序游戏（数感）、条件分类（推理意识）、规律递推（模型意识）、迷宫行走（空间观念）
小学信息科技 信息意识、计算思维、数字化创新与发展、信息社会责任 指令执行（计算思维）、活动设计（数字化创新）、规则遵守（信息社会责任）、问题调试（信息意识）

不插电编程是两个学科素养落地的“具象化载体”，让抽象素养通过游戏活动可感可练。

数学游戏实验和不插电编程的区别

数学游戏实验 和不插电编程的区别
对比维度 数学游戏实验 不插电编程
核心目标 巩固数学知识点（如运算、几何、概率），提升数学应用能力 培养计算思维（顺序、条件、循环、调试），为图形化 / C++ 编程打思维基础
思维指向 聚焦 “数学逻辑”（如数量关系、空间推理、规律探究） 聚焦 “编程逻辑”（如指令序列、条件判断、重复执行、错误修正）
与学科 / 编程的关联 仅服务于数学学科，无后续编程衔接要求 跨数学 + 信息科技，每一个活动都要预留 “编程衔接接口”（如对应图形化积木、C++ 语法思想）
设计重点 趣味性 + 数学知识落地（让学生在游戏中练数学） 趣味性 + 计算思维落地 + 编程衔接（让学生在游戏中懂编程逻辑）

三、课程实施与试点安排

不插电编程在很大程度上以建构主义方法为基础：根据几个简单规则，给学生设置挑战。在解决这些挑战的过程中，他们将自行发现强有力的想法。这不仅是比较难忘的学习方法，还能让学生感觉到可自主掌握这些想法。

本学期试点

  • 本学期在二年级试点。

  • 上课形式：数学社团或课后服务时间开展，每次30分钟左右。

下学期推广

  • 开设 “不插电编程” 专项社团，覆盖一、二年级，形成常态化社团课程

  • 长远看、逐步向三、四年级延伸。

四、任务与分工

任务

  1. 授课：7 位老师可重复授课（学生不同），本学期聚焦 1 个专题，完成 5 节课并打磨。

  2. 推进：尽早启动，统一 “数学知识点 + 不插电活动 + 衔接设计” 模板。

  3. 成果：留存过程材料，期末形成可复用课程资源。

  4. 研讨：固定集体备课时间。

时间节点

  • 教学第12周召集动员会

  • 教学第13周备课、准备教学用具

  • 教学第14周上课
